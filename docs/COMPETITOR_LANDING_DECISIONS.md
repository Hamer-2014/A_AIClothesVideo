# 竞品首页拆解与本项目落地决策

版本：Decision 1

日期：2026-07-28

调研对象：WearMind（`aishirt.app`）、The New Black、WearView
关联文档：[PRD](PRD.md)、[首页内容设计](LANDING_PAGE_CONTENT_DESIGN.md)、[UI Guidelines](AI_CLOTHES_VIDEO_UI_GUIDELINES.md)、[营销上线计划](MARKETING_LAUNCH_PLAN.md)

## 1. 本文解决什么问题

本文不重新发明一套首页，也不要求照搬竞品。它负责记录：

- 三个竞品分别用什么方式解释产品、证明结果和推动注册。
- 哪些模式适合 AI Clothes Video，哪些会把 MVP 带偏。
- 当前首页结构需要保留、调整和延后的内容。
- 后续视觉与前端实施应遵守的优先级和验收边界。

首页的唯一主任务是：

> 让已有服装商品图的跨境卖家在首屏理解“三张同款素材生成一条商品视频”，看到真实结果，并开始一次试用。

## 2. 三个竞品的结构模型

| 竞品 | 核心受众 | 首屏承诺 | 主要证据 | 转化方式 | 主要风险 |
|---|---|---|---|---|---|
| WearMind | POD 卖家、独立设计师、电商卖家 | Design / Try-On / Video 一体化 | 首屏视频、首页内嵌工作台、社区作品、评价、价格 | 免费点数 + 多个工具入口 | 定位过宽，首页工具与视频主线互相争夺 |
| The New Black | 时尚品牌与创意团队 | 为品牌提供完整 AI 时尚平台 | 商品与模特结果同屏、国家覆盖、渠道连接、完整工作流 | Create now + Watch Demo | 品牌感强但功能过多，视频能力不是主线 |
| WearView | 时尚电商品牌 | 用 AI 模特替代传统拍摄并降低成本 | 大量结果图、品牌数、三步流程、对比、评价、平台 | 立即试用 + 长销售页重复 CTA | 强数字声明需要证据，首页过长，核心仍是模特图 |

### 2.1 WearMind 可借模式

- 在首页直接出现产品操作模型，缩短“它到底怎么用”的理解时间。
- 主 CTA 与查看视频结果的次 CTA 并列。
- 用真实结果、使用流程、价格和 FAQ 形成完整证据链。

不采用：

- 不扩展为设计、虚拟试穿、Prompt Generator 等综合工具平台。
- 不用“赠送多少 Credits”代替“能免费生成什么”的说明。
- 不在首页放一个看似可上传、实际不可完成的伪工作台。

### 2.2 The New Black 可借模式

- 用真实服装输入与结果承担首屏视觉，不使用抽象 AI 装饰。
- 采用高对比、强排版、少颜色的时尚编辑式表达。
- 用短工作流说明产品价值，不先解释模型和技术供应商。

不采用：

- 不展示团队、批量生成、Brand DNA、跨渠道发布等未进入 MVP 的能力。
- 不用高端品牌视觉掩盖生成边界和真实效果证据。
- 不把多个 Studio 作为首页导航主结构。

### 2.3 WearView 可借模式

- 从卖家的商品交付场景出发，而不是从 AI 技术出发。
- 先展示结果，再解释三步流程、适用场景和商业规格。
- 移动端采用单列叙事和全宽 CTA，保证广告流量能快速行动。

不采用：

- 在没有统计证据前，不使用“节省 90%”“提升转化 35%”“30 秒出片”等承诺。
- 不用虚构品牌 Logo、客户评价、生成数量或成功率。
- `了解如何运作` 必须进入真实说明位置，不能伪装成注册 CTA。

## 3. 竞品能力到本项目的映射

| 用户问题 | 竞品常用答案 | 本项目应该怎样回答 | 证据来源 |
|---|---|---|---|
| 这是什么 | AI fashion platform / AI model generator | 三张服装图生成一条商品宣传视频 | H1、副文案、真实成片 |
| 我需要上传什么 | 任意图片或商品图 | 同一件服装的一种三图协议 | 三张真实输入图、协议说明 |
| 能得到什么 | 模特图、设计图、视频或多工具结果 | 8、16、24 秒完整视频；40 秒仅付费 Beta 开关开放时出现 | 规格摘要、价格页 |
| 为什么更可信 | 品牌数、评价、ROI 数据 | 素材边界、镜头权限、真实输入输出、生成后 QA | 真实案例和流程说明 |
| 怎么开始 | 注册、免费点数、立即生成 | 免费生成 1 条 8 秒低清水印视频 | 主 CTA 与试用限制 |
| 适合哪里使用 | Shopify、TikTok、Reels 等 | 商品页、TikTok / Reels 测款 | Hero 与 Preset 用途 |
| 失败怎么办 | 多数首页不说明 | 任务状态、重试与点数释放/退款按真实规则处理 | 价格页、FAQ、任务页 |

## 4. 当前首页审查结论

当前 `src/app/page.tsx` 已经实现以下正确方向，应保留：

- 全幅真实成片 Hero，而不是渐变、插画或伪造产品截图。
- H1 直接表达“三张服装图 -> 一条商品视频”。
- 未登录访客和已登录用户使用不同主 CTA。
- 首屏明确免费试用限制，不把限制藏到价格页。
- 三张真实输入与同一条真实输出在首页完成证据闭环。
- Style Preset 用用户用途表达，不暴露内部镜头模板 ID。
- 只展示 8、16、24 秒与常用比例，不暴露供应商分辨率参数。
- 页面采用完整区段和编辑式网格，没有卡片套卡片。

### 4.1 P0 调整

1. 英文主导航不应把 `Privacy` 和 `Terms` 放在一级导航。它们属于页脚 reference 信息。英文一级导航应与转化任务一致，优先使用 `Three-image workflow`、`Pricing`、`FAQ`。
2. 保留单一主 CTA。`查看真实三图样例` 只能滚动到真实案例，不得跳注册。
3. 首页所有视频、图片和文案必须继续使用同一个真实 SKU，不能为了画面丰富混入不对应的素材。
4. 首屏继续说明试用的时长、水印、音频和镜头限制；不改成含糊的“免费 Credits”。

### 4.2 P1 调整

1. 将“稳定机制”从防御式规则说明收敛为用户能扫描的生成流程；详细规则继续放到三图专题页和 FAQ。
2. Style Preset 只有在存在对应真实输出时才升级为视频或图片预览。当前没有三套真实输出时，宁可保留文字，也不放伪造缩略图。
3. 当至少准备 3 个不同品类、已授权且真实生成的 SKU 后，再增加案例入口或案例页。首页不先做空案例墙。
4. 在输出规格区域保留价格页入口；不把完整三档点数包复制到首页。

### 4.3 暂缓

- 客户 Logo、客户评价、成功率、节省比例、转化提升数据。
- 团队协作、批量 SKU、品牌 DNA、Shopify 直发、社媒自动发布。
- 首页可直接上传的完整工作台。上传涉及登录、素材权利声明和三图协议，应在工作台完成。
- 大量用途页、行业页和案例页。只有真实资产和搜索意图验证后再扩展。

## 5. 首页任务模型

| 层级 | 用户目标 | 页面支持 |
|---|---|---|
| Primary goal | 判断产品是否能把现有商品图变成可用视频，并开始试用 | Hero、真实结果、主 CTA |
| Secondary goal | 理解为什么需要三张图以及系统怎样限制镜头 | 三图证据、简短流程 |
| Low-frequency goal | 了解具体价格、素材要求和生成边界 | Pricing、FAQ、三图专题页 |
| Rare goal | 处理授权、侵权、异常任务和退款争议 | 条款、Takedown、任务与账单页 |

## 6. 首页信息优先级

| 信息项 | 角色 | 首屏 | 显示条件 | 容器 |
|---|---|---:|---|---|
| 产品承诺 | action-critical | 是 | 始终 | Hero 文本层 |
| 真实成片 | decision-supporting | 是 | 视频或 poster 可用 | Hero 媒体层 |
| 主 CTA | action-critical | 是 | 始终 | Hero 操作区 |
| 试用限制 | decision-supporting | 是 | 未登录 | CTA 邻近短句 |
| 生成边界短句 | decision-supporting | 是 | 始终 | Hero 文案末尾 |
| 三张输入图 | decision-supporting | 露出下一节 | 始终 | 证据区 |
| 完整流程 | decision-supporting | 否 | 滚动后 | 普通区段 |
| Preset | decision-supporting | 否 | 滚动后 | 三列编辑式区段 |
| 价格详情 | reference | 否 | 主动查看 | `/pricing` |
| FAQ 与授权 | reference / exception-handling | 否 | 主动查看或遇到问题 | 专门页面 |

首屏最多保留三个主要视觉群组：导航、Hero 文案与操作、真实成片。不要加入统计条、Logo 墙、Preset 卡片或 FAQ。

### 6.1 Information architecture / content audit

| 内容类别 | 包含内容 | 当前隐藏原因 | Reveal trigger | Container |
|---|---|---|---|---|
| must-see-now | 核心承诺、真实成片、主 CTA、试用限制、边界短句 | 不隐藏 | 首次进入 | Hero |
| next-step-only | 三张输入图、流程、Preset、输出规格 | 用户先要判断结果是否值得继续了解 | 向下滚动 | 普通页面区段 |
| error-only | 视频加载失败、试用不可用、素材不合格、任务失败 | 正常状态出现会增加焦虑并稀释主任务 | 对应失败状态发生 | poster fallback、内联状态、任务页 |
| on-demand-reference | 价格详情、完整 FAQ、授权、隐私、条款、Takedown | 低频信息不应占用首屏 | 用户点击明确链接 | 专门页面或页脚 |
| keep-off-first-viewport | 统计指标、Logo 墙、客户评价、完整 Preset 列表 | 当前缺少可审计证据，且会形成第四视觉群组 | 真实数据与资产达到实施门槛 | 案例页、后续社会证明区段 |

Deferred block 必须同时具备 `hidden_now_because`、`reveal_trigger` 和 `container`。无法说明这三项的内容不得直接加入首页。

## 7. 最终首页顺序

1. **Header**：品牌、三图流程、价格、FAQ、登录/工作台、语言。
2. **Hero**：真实成片、核心承诺、主 CTA、真实样例锚点、试用限制与一句边界。
3. **Input -> Output Evidence**：三张真实素材与同一条真实结果。
4. **Controlled Workflow**：同款确认、素材边界、支持镜头、生成后 QA。
5. **Style Presets**：极简棚拍、电商主图动效、社媒氛围短片。
6. **Delivery Specs**：8/16/24 秒、常用比例、完整任务、价格入口。
7. **Final CTA**：从一个 SKU 开始，辅助入口指向素材要求。
8. **Footer**：隐私、条款、可接受使用、Takedown 与其他 reference 页面。

不在首页重复完整 FAQ、完整价格表和完整三图协议。它们分别由专门页面承接。

## 8. Hero 决策

当前 Hero 文案继续使用，不因竞品研究改成泛化平台表述。

### 中文

- Eyebrow：`为跨境服装卖家制作商品短视频`
- H1：`三张服装图，生成一条商品宣传视频`
- Supporting copy：`上传同一件服装的正面、背面与细节图。系统先检查素材，再匹配可用镜头，生成适合商品页和社媒测款的 8、16 或 24 秒视频。`
- Primary CTA：`免费生成 1 条试用视频`
- Secondary CTA：`查看真实三图样例`
- Boundary：`没有背面图，不生成背面；没有细节图，不编造细节。`

### English

- Eyebrow: `Product videos for independent clothing sellers`
- H1: `Three clothing images. One product video.`
- Supporting copy: `Upload front, back, and detail images of the same garment. The system checks the material first, then matches supported shots for an 8, 16, or 24-second product or social video.`
- Primary CTA: `Create a free trial video`
- Secondary CTA: `View the real three-image sample`
- Boundary: `No back image means no back view. No detail image means no detail close-up.`

## 9. CTA 路径

```text
未登录主 CTA
  -> /login?next=/workspace?mode=trial&preset=minimal_studio
  -> 登录与邮箱验证
  -> /workspace?mode=trial&preset=minimal_studio
  -> 选择三图协议并接受素材权利声明
  -> 上传三个明确角色的素材

已登录主 CTA
  -> /workspace

查看真实样例
  -> 当前页面 #source-proof

查看价格
  -> /pricing

查看素材要求
  -> /faq 或 /three-images-to-clothing-video
```

首页不能在登录和权利声明之前保存用户素材。可以展示真实工作台预览，但预览必须明确是示例，不能伪装成已经开始上传。

## 10. 视觉方向

公开站采用 **Bold Editorial**，工作台采用 **Minimal Premium SaaS**。两者共享品牌 token，但不混成营销卡片式工作台。

- 颜色：纸白、石墨黑、暖灰、珊瑚红主操作；不改成 WearMind 的蓝色，也不使用紫蓝渐变。
- 字体：高对比、短标题、正常字距；紧凑面板不使用 Hero 尺度标题。
- 媒体：真实服装图和真实生成视频是唯一主装饰。
- 布局：首页使用完整区段与不对称编辑式网格；工作台让三图上传画布占据主舞台。
- 卡片：只用于单个真实案例或工具容器，不把每个卖点包装成浮动卡片。
- 动效：视频静音播放；文字和素材只做一次短进入；支持 `prefers-reduced-motion`。
- 圆角：公共工具与卡片不超过 8px；按钮和图标按现有 token。

## 11. 响应式要求

### 390 x 844

- Header 只保留品牌、登录/试用、语言和菜单。
- Hero 文案、CTA、视频按单列排列；主 CTA 全宽，次 CTA 不与主 CTA 争夺强调。
- 首屏必须看见主 CTA，并露出真实视频或下一证据区。
- 三张输入图保持三列，但只保留短标签；详细说明移到后续或隐藏。

### 768 x 1024

- Hero 可使用上下结构或窄双栏，不能压缩文字覆盖服装主体。
- Preset 和流程最多两列，避免窄三列造成长段落。

### 1440 x 900

- Header 与 Hero 合计控制在首屏内，并露出下一节入口。
- Hero 文案不超过约 640px；视频主体不能被遮挡或暗化到无法检查服装。
- 真实三图和结果使用稳定比例，加载状态不能造成布局跳动。

## 12. 实施门槛

### 现在可以做

- 统一中英文一级导航的信息角色。
- 保持当前 Hero、真实三图和真实视频证据链。
- 收敛流程文案，避免首页变成长规则页。
- 验证 390、768、1440 三个视口与 reduced motion。

### 需要真实资产后再做

- Preset 视觉预览：每种 Preset 至少一条与输入素材对应的真实输出。
- 案例页：首页至少准备 3 个不同服装品类的授权案例。
- 评价与指标：必须有可审计样本和计算口径。

### 不进入当前 Goal

- 重做工作台。
- 新增团队、批量、发布平台或虚拟试穿能力。
- 新增 SEO 内容集群或复制竞品的大量用途页。

## 13. 验收标准

- 用户只看首屏就能回答：上传什么、得到什么、免费试用是什么。
- 页面第一屏只有一个主 CTA，次 CTA 不发生注册跳转。
- 输入素材和结果视频属于同一个真实 SKU。
- 没有未经证实的客户数量、节省比例、成功率或转化提升声明。
- 中英文一级导航都服务产品理解和转化，隐私与条款留在页脚。
- 390px 宽度下按钮不截断、页面无横向滚动、视频不遮挡文案。
- 已登录访客看到工作台 CTA，未登录访客看到试用 CTA。
- 登录、权利声明和三图上传顺序符合 PRD，不在公开首页提前保存素材。
