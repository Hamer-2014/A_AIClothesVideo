# Public Site Internationalization Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make English the default public-site language, provide stable `/zh` Chinese URLs and an accessible language switcher, and translate all public, authentication, pricing, FAQ, and legal surfaces without changing generation behavior.

**Architecture:** The visible URL is the locale source of truth: unprefixed routes are English and `/zh/...` routes are Chinese. `src/proxy.ts` rewrites Chinese URLs to the existing App Router pages while forwarding `x-site-locale`; server helpers read that header, shared links preserve the locale prefix, and client components receive an explicit locale prop. Admin pages and deep workspace/job component translation are deferred to phase two.

**Tech Stack:** Next.js 16 App Router and Proxy, React 19, TypeScript, Tailwind CSS 4, Vitest, Testing Library.
